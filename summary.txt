CuraBot

I built CuraBot as a full-stack Hybrid RAG application combining local Hugging Face all-MiniLM-L6-v2 embeddings, Qdrant semantic search, and Gemini 2.5 Flash for response generation. I implemented semantic retrieval and real-time crisis detection using regex matching and semantic sliding-window analysis, with crisis alerts delivered through Twilio and Telegram. I developed the backend with FastAPI and Uvicorn, used MongoDB Atlas for user and conversation data, and implemented authentication with Google OAuth2, JWT sessions, and Bcrypt password hashing. On the frontend, I used React 19, TypeScript, and Vite with streaming responses. I also designed the system so embeddings are generated locally before information is sent to the LLM, adding a privacy-oriented component to the architecture.
